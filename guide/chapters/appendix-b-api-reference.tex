\chapter{API Reference}
\label{ch:api-reference}

The \sysname{} backend exposes a REST API at \ic{http://localhost:8000}.
Interactive Swagger documentation is available at \ic{/docs}.
All endpoints requiring authentication expect a \ic{Bearer} token in the
\ic{Authorization} header. Unauthenticated requests fall back to the
\ic{anonymous} user scope.

\paragraph{Query parameters for \ic{/api/search}:}
\begin{description}[style=nextline]
  \item[\ic{query}] Search string (min 2 chars, required).
  \item[\ic{type}] Filter by \ic{decision} or \ic{entity}.
  \item[\ic{expand}] Enable graph expansion on results (\ic{true}/\ic{false}).
  \item[\ic{depth}] Expansion depth when \ic{expand=true} (1--3, default 1).
\end{description}

%% ─── SSE Events ─────────────────────────────────────────────────────
\section{SSE Events for \ic{/api/ask}}
\label{sec:sse-events}

The \ic{/api/ask} endpoint returns a \ic{text/event-stream} response.
Each event has an \ic{event:} type line followed by a \ic{data:} JSON
payload.

\begin{small}
\begin{tabularx}{\textwidth}{l X}
\toprule
\textbf{Event} & \textbf{Payload} \\
\midrule
\ic{context} & Retrieved subgraph JSON: \ic{\{nodes, edges, seed\_ids\}}.
  Each node includes \ic{type} (\ic{decision}/\ic{entity}), \ic{is\_seed},
  and a \ic{data} object with the node's properties. \\
\ic{token} & LLM output chunk: \ic{\{text: "..."}\}. Concatenate all
  \ic{token} events to build the full answer. \\
\ic{done} & Stream complete: \ic{\{token\_count: N\}}. \\
\ic{error} & Error detail: \ic{\{detail: "..."}\}. \\
\bottomrule
\end{tabularx}
\end{small}

%% ─── WebSocket Protocol ────────────────────────────────────────────
\section{WebSocket Protocol for Capture}
\label{sec:ws-protocol}

Connect to \ic{/api/capture/sessions/\{id\}/ws} to stream a capture session
in real time. The protocol follows this sequence:

\begin{enumerate}
  \item \textbf{Connect} --- Client opens the WebSocket connection.
  \item \textbf{Send message} --- Client sends JSON:
    \ic{\{"content": "user's answer"\}}.
  \item \textbf{Receive chunks} --- Server streams
    \ic{\{"type":"chunk", "content":"...", "entities":[...]\}}.
  \item \textbf{Completion} --- Server sends
    \ic{\{"type":"complete"\}} when the response is finished.
  \item \textbf{Repeat} --- Steps 2--4 repeat until the session ends.
\end{enumerate}

\begin{warning}
Messages are rate-limited to 20 per minute per session. Messages exceeding
10\,KB are rejected. The server trims conversation history at 50 messages.
\end{warning}

%% ─── Example curl Commands ─────────────────────────────────────────
\section{Example \ic{curl} Commands}
\label{sec:api-examples}

\paragraph{Register a user.}
\begin{lstlisting}[style=bash]
curl -X POST http://localhost:8000/api/users/register \
  -H "Content-Type: application/json" \
  -d '{"name":"Demo","email":"ali@demo.com","password":"demo1234"}'
\end{lstlisting}

\paragraph{Search decisions and entities.}
\begin{lstlisting}[style=bash]
curl "http://localhost:8000/api/search?query=postgres&type=entity"
\end{lstlisting}

\paragraph{Ask a question (SSE stream).}
\begin{lstlisting}[style=bash]
curl -N "http://localhost:8000/api/ask?q=Why+did+we+choose+Redis&depth=2&top_k=5" \
  -H "Authorization: Bearer $TOKEN"
\end{lstlisting}
